# Banking Data Platform

An end-to-end data engineering pipeline designed to ingest, validate, and process core banking transactions into a unified analytical reporting engine.

## Tech Stack & Architecture
- **Language & Pipeline:** Python 3.12, SQL[cite: 2]
- **Storage & Engine:** DuckDB & Columnar Parquet[cite: 2, 4]
- **Data Governance:** Schema validation, quarantine gates, and financial reconciliation[cite: 5]
- **Analytical Data Model:** Consolidated Single Analytical Master Table (One Big Table)[cite: 2]
