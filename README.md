# Banking Data Platform

An end-to-end data engineering pipeline designed to ingest, validate, and process core banking transactions into a unified analytical reporting engine.

## Tech Stack & Architecture
- **Language & Pipeline:** Python 3.12, SQL
- **Storage & Engine:** DuckDB & Columnar Parquet
- **Data Governance:** Schema validation, quarantine gates, and financial reconciliation
- **Analytical Data Model:** Consolidated Single Analytical Master Table (One Big Table)
