# Banking Enterprise Data Platform

An end-to-end modern data engineering platform designed to ingest, validate, and model transactional and customer data into a governed, audit-ready data warehouse.

## Tech Stack & Architecture
- **Language & Pipelines:** Python 3.12, SQL
- **Warehouse Modeling:** Kimball Star Schema, SCD Type 2
- **Data Quality & Governance:** Schema enforcement, reconciliation checks, quarantine isolation
